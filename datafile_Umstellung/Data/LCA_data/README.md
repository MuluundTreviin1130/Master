# Brightway static LCA setup (clean)

This folder contains a minimal, non-redundant Brightway (Brightway2/3) toolchain to:

1. Bootstrap a Brightway project
2. Install `biosphere3`
3. Install LCIA methods (EF v3) **with a patch** for the `['biosphere3', uuid]` identifier issue
4. Import ecoinvent (ecoSpold2)
5. Search and inspect activities
6. Calculate EF16 category results for any activity
7. Export per-technology JSONs consumed by the optimization model

## Directory layout

```text
Data/LCA_data/
  categories.json                # internal category definition (keys used by your optimization)
  mappings/
    method_map_efv3_noLT.json     # category -> Brightway method tuple (already filled)
  proxies/
    static/AT/
      BESS_infra.json
      Grid_op.json
      PV_infra.json
      PV_op.json
  static/AT/
    (generated by exporter)
    BESS.json
    Grid.json
    PV.json
  scripts/
    00_check_environment.py
    01_bootstrap_project.py
    02_install_lcia_methods_patched.py
    04_import_ecoinvent.py
  tools/
    brightway_search.py
    brightway_inspect_activity.py
    brightway_list_methods.py
  calculators/
    brightway_calculate_activity_ef16.py
  exporters/
    brightway_export_static_json.py
```

## Expected runtime order (fresh project)

Run these from your repo root (so `Data/` is a sibling of `Optimization/`, `Sustainability/`, etc.).

1) **Bootstrap project + biosphere3**

```powershell
& "<path>\.venv\Scripts\python.exe" "Data\LCA_data\scripts\01_bootstrap_project.py" --project my_lca_project
```

2) **Install LCIA methods (patched)**

```powershell
& "<path>\.venv\Scripts\python.exe" "Data\LCA_data\scripts\02_install_lcia_methods_patched.py" --project my_lca_project
```

3) **Import ecoinvent** (ecoSpold2 directory)

```powershell
& "<path>\.venv\Scripts\python.exe" "Data\LCA_data\scripts\04_import_ecoinvent.py" --project my_lca_project --db "ecoinvent 3.11 cutoff" --ecospold "C:\\path\\to\\datasets"
```

4) **Sanity check**

```powershell
& "<path>\.venv\Scripts\python.exe" "Data\LCA_data\scripts\00_check_environment.py" --project my_lca_project
```

## How to search and inspect activities

Search:

```powershell
& "<path>\.venv\Scripts\python.exe" "Data\LCA_data\tools\brightway_search.py" --project my_lca_project --db "ecoinvent 3.11 cutoff" --query "market for electricity, high voltage" --limit 10
```

Inspect (use code from search output):

```powershell
& "<path>\.venv\Scripts\python.exe" "Data\LCA_data\tools\brightway_inspect_activity.py" --project my_lca_project --db "ecoinvent 3.11 cutoff" --code "f281d8a42852c63a4f61156aba8d0b80" --n 20
```

## How to calculate EF16 impacts for an activity

```powershell
& "<path>\.venv\Scripts\python.exe" "Data\LCA_data\calculators\brightway_calculate_activity_ef16.py" --project my_lca_project --activity "ecoinvent 3.11 cutoff" "f281d8a42852c63a4f61156aba8d0b80" --amount 1
```

Notes:
- Output is printed in scientific notation to avoid misleading `0` due to rounding.
- A JSON file is also written next to the script for quick inspection.

## Export JSONs for the optimization model

1) Edit proxy files under `Data/LCA_data/proxies/static/AT/` (choose the correct `activity_key`s and scaling factors).
2) Run exporter:

```powershell
& "<path>\.venv\Scripts\python.exe" "Data\LCA_data\exporters\brightway_export_static_json.py" --project my_lca_project --country AT
```

It creates/overwrites:
- `Data/LCA_data/static/AT/BESS.json`
- `Data/LCA_data/static/AT/Grid.json`
- `Data/LCA_data/static/AT/PV.json`

These are shaped as:

```json
{
  "infra": {"climate_change": 0.0, ...},
  "op":    {"climate_change": 0.0, ...},
  "meta":  {"technology": "Grid", "country": "AT", "project": "my_lca_project", ...}
}
```

This matches your current facade expectation (`infra`, `op`, `meta`).

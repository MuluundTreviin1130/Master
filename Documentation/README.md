# Documentation

Dieser Ordner dokumentiert die wesentlichen Umbau- und Arbeitschritte im Repo.

Ziel:

- Umbauten nicht nur im Chat verlieren
- den Pfad von Architektur- und Modellentscheidungen knapp nachvollziehbar halten
- zwischen `TODO` und finalem Code eine schlanke Arbeitsspur haben

Grundsatz:

- `Documentation/Planning/TODO.md` ist der kanonische Ort fuer offene Punkte
- `Documentation/Sources/` ist der kanonische Ort fuer Daten- und Literaturquellen
- `Documentation/` dokumentiert erledigte oder laufende Umbaupfade in knapper Form

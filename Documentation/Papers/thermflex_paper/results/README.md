# Results Layer

This folder is the curated paper-facing results layer for the Vienna DH thermflex
paper.

Purpose:

- collect the paper-relevant result interpretation in one place
- reference the raw gold and analysis bundles without duplicating them
- provide a stable intermediate layer from which figures and tables can be built

Principle:

- raw run artifacts remain under `Optimization/run/results/...`
- this folder contains curated summaries, decisions, and mappings

Main files:

- `source_manifest.json`
- `00_source_bundles.md`
- `01_core_dispatch_results.md`
- `02_representative_day_results.md`
- `03_two_stage_results.md`
- `04_cohort_mechanism_results.md`
- `05_biobjective_results.md`
- `06_surrogate_status.md`

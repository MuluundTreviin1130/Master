# Figures

This layer is intentionally flat.

Purpose:

- keep active paper figures easy to scan in one directory
- avoid deep figure subfolders for a small manuscript workspace
- keep figure-specific builders directly next to the assets they create
- keep superseded or exploratory figures under `old/` without deleting them

Convention:

- final assets directly in this folder
- figure-specific builders directly in this folder when they are paper-only
- superseded figures move to `old/`

Active mechanism figures currently include:

- `fig_06_cohort_duration_daily_sums.png`: cohort and duration shift/release sums.
- `fig_07_flexibility_outcome_atlas.png`: day-level system KPI atlas from Table 09.
- `fig_10_source_redispatch_facets.png`: representative-day source redispatch, showing that the current active upper-only path mainly relieves the peak boiler while gas-CHP heat stays almost unchanged.

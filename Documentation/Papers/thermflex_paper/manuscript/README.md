# Manuscript

This folder contains the text-first manuscript layer for the Vienna DH
thermflex paper.

Purpose:

- keep the classical paper sections in one place
- separate manuscript text from curated result interpretation
- let the paper text reference the `results/`, `figures/`, `tables/`, and
  `appendix/` layers cleanly

Current structure:

- `00_title_abstract_keywords.md`
- `01_introduction.md`
- `02_methods.md`
- `03_results.md`
- `04_discussion.md`
- `05_conclusion.md`
- `06_limitations.md`
- `07_appendix_overview.md`
- `08_figure_table_plan.md`
- `09_references.md`

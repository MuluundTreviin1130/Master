% Table T7 - Meta-review of existing review studies in the
% intersection of surrogate modeling, energy-system optimization,
% MOO and MES. Each row positions one prior review along the four
% scope axes that this work targets and identifies the gap that the
% prior review leaves open.
%
% Selection. The candidates were drawn from two sources: (i) the
% strict review classifier in references/scan_review_candidates.py,
% which fires a review flag only if at least one of {title, abstract,
% keywords} carries an unambiguous review marker (e.g. ":\,a review",
% "comprehensive review", "literature review", "bibliometric
% analysis", "scientific mapping", "state-of-the-art"); and (ii) the
% externally-supplied review PDFs in
% paper_library/fulltexts/, captured in references/external_reviews.bib
% because they fall outside the Scopus search-string keyword cone
% (e.g. Comp. Chem. Eng., Comp. Intelligence and Neuroscience, math
% journals, MCDM-specific venues). Each candidate was abstract-
% verified to confirm it is in fact a review and not a single-system
% study that merely mentions a review marker. Three earlier T7 rows
% (Xiao2018, Cao2023, Perera2019191) failed that abstract test --
% they are comparison or methods studies -- and were dropped.
%
% The thirty-two rows below are arranged in four blocks
% (surrogate methodology, MES domain, MOO and MCDM methodology, ESM
% optimization). The trailing "This work" row positions the present
% review against the four scope axes.

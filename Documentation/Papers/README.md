# Papers

Dieser Layer haelt paperspezifische Scope-, Methoden- und Ergebnisnotizen getrennt
von allgemeiner Repo-Dokumentation.

Ziel:

- Papers nicht nur ueber Run-Namen, Chats oder verstreute Analysis-Skripte tragen
- Forschungsfragen, Main Cases, Fallnamen und offene Restpunkte explizit festhalten
- einen klaren Uebergang zwischen Modellkern und Paper-Inszenierung schaffen

Aktuell:

- `dh_thermflex_vienna.md`
  enger Paperschnitt fuer Wiener District Heating mit Gebaeude-Thermflexibilitaet
- `thermflex_paper/`
  kuratierter Manuskript-Workspace mit klassischen Paper-Sektionen, Figuren-,
  Tabellen-, Appendix- und Manifest-Layern

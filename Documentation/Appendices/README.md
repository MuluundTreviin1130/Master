# Appendices

This folder contains reproducible paper-appendix artifacts that are generated
from the repo SSOT files rather than edited by hand.

Current appendix artifacts:

- `vienna_building_model_parameters_appendix.docx`
- `vienna_building_model_parameters_appendix.md`

Generator:

- `build_vienna_building_parameter_appendix.py`

Purpose:

- document the Vienna building-model parameterization for the current paper path
- keep archetype, cohort, calibration, control, and thermflex parameter tables
  synchronized with the actual repo state
- make source notes explicit, including where parameters are still pragmatic
  V1 assumptions or legacy compatibility fields rather than literature-backed
  SSOT
